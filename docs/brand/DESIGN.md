# Sample Project — Design Reference

## Palette

| Token | Hex | Usage |
|---|---|---|
| Ink (primary text) | `#0B1426` | Headings, body text |
| Background | `#F8FAFC` | Page background |
| Accent (blue) | `#2563EB` | Links, buttons, interactive elements |
| Accent hover | `#1D4ED8` | Button hover, link hover |
| Muted text | `#64748B` | Secondary text, captions |
| Border | `#E2E8F0` | Dividers, card borders |
| Surface | `#FFFFFF` | Cards, modals, elevated surfaces |
| Success | `#16A34A` | Positive feedback |
| Warning | `#EAB308` | Caution states |
| Error | `#DC2626` | Error states |

## Typography

| Role | Font | Weight | Size |
|---|---|---|---|
| Headings | Inter | 600 (semibold) | 2rem / 1.5rem / 1.25rem (h1/h2/h3) |
| Body | Inter | 400 (regular) | 1rem / 1.625 line-height |
| Mono / code | JetBrains Mono | 400 | 0.875rem |
| Small / captions | Inter | 400 | 0.875rem |

## Spacing

- Base unit: 4px
- Section padding: 64px vertical
- Card padding: 24px
- Component gap: 16px
- Max content width: 1200px

## Mood

Clean editorial. Generous whitespace, sharp type hierarchy, minimal decoration. Content-forward — the design gets out of the way and lets the words do the work.

## Image style

Photography: natural light, unsaturated. Illustrations: flat line art, single accent color. Icons: Lucide set, 24px, stroke width 1.5.
